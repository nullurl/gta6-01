**SOLMARA** — an original open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun's "Make GTA 6" bounty. You are Rae Vega, a wheelman new to Solmara, a sun-soaked coastal city. Explore the city on foot and by car, steal cars, outrun the Solmara PD through a 5-star wanted system, take taxi fares, and work five story missions from a first fare to the big score. The game is plain static files — it plays offline in desktop Chrome with keyboard and mouse, no build step, no network request.

## Run it

```sh
python3 -m http.server 8080 --directory game
# then open http://localhost:8080
```
